# Python conventions — pdomain-ui

Read by the `writing-python` skill on invocation. Project deltas only; the procedure, the
strict baseline, and the gate-resolution order live in the plugin.

This is a TypeScript/React library. The only Python is the repo-maintenance scripts under
`scripts/`, type-checked under basedpyright strict. There is no Python package to publish.

## Gate

Run the Python gate through these Make targets (each wraps `uv run`, which syncs the dev
dependency-group first):

- Lint: `make py-lint` (`uv run ruff check scripts`)
- Format check: `make py-format-check`; apply with `make py-format`
- Typecheck: `make py-typecheck` (`uv run basedpyright`, strict)
- All three: `make py-static-check` — also runs inside `make static-check` and `make ci`.

There are no Python tests yet. Do NOT use the bare `make lint` / `make typecheck` targets for
Python: those are the JavaScript (ESLint / tsc) gate.

## Deltas the resolver can't infer

- First-party import package: `scripts` (`scripts/__init__.py` exists). Set
  `[tool.ruff.lint.isort] known-first-party = ["scripts"]` if cross-module imports appear.
- Opt-in ruff families beyond the baseline: **`S`** (flake8-bandit) is on, because
  `scripts/update_github_actions.py` runs `subprocess` and rewrites GitHub Action SHAs. This
  keeps its `# noqa: S603` a valid, used suppression.
- basedpyright is pinned to `pythonVersion = "3.12"` (the `requires-python` floor) even though
  the local venv may be newer.
